# Sirius API診断（Issue #2用）

製品とは別の一時的なChrome拡張です。Cookieや認証コードを取得せず、ログイン済みブラウザからの同一オリジンGETを確認します。
インストール直後に通信せず、「読み取り診断を実行」を押した時だけ動作します。

## 実行

1. リポジトリで `npm ci` と `npm run build:probe` を実行します。
2. Chromeの `chrome://extensions` で開発者モードを有効にし、「パッケージ化されていない拡張機能を読み込む」から **`probe-dist`** を選びます。製品用の `dist` とは別です。
3. 同じChromeでSiriusにログインし、ホームまたは科目の課題一覧を再読み込みします。
4. 右下の「Sirius API診断 v2（開発用）」で「読み取り診断を実行」を1回押します。旧表示の場合は拡張管理画面で診断拡張を再読み込みしてからページを開き直します。
5. 結果欄のJSONを確認します。診断後は拡張を削除できます。

科目一覧のGETを1回、表示中の課題一覧の科目を優先し、ナビゲーション内の科目と合わせて最大2科目の課題と小テストを各1回取得します。全科目を取得する診断ではありません。
最大5リクエストを順番に実行し、それぞれ15秒で打ち切ります。401/429で残りを中止し、リダイレクトは追いません。

## 出力する情報

- HTTP状態、応答の形式、固定された診断用エラー分類。
- 許可したプロパティ名と型、配列の空/非空、先頭要素の構造。
- 許可していないプロパティは名前も値も出さず、省略数だけを示します。任意のキーを持つprops等の中身は出しません。
- 課題一覧がある場合、科目と項目IDでAPIと照合し、公開日時・締切日時と一致/不一致/判定不能になった件数を示します。ID不明・重複は成功扱いにしません。画面で現在表示されている行だけが対象です。

文字列・数値・真偽値の実際の値、課題名、科目名、ID、URL、本文、認証情報は出力しません。ブラウザ内に永続保存せず、開発者サーバーへ送信しません。

日時の照合は `epochSecond` を秒、`nano` をナノ秒と解釈し、日本時間で分単位まで公式画面と比較する仮説検証です。`openTime` は公開日時、`dueTime` / `closeTime` / `dropDeadTime` は締切日時とそれぞれ比較します。同じ値のフィールド同士の意味や、秒以下の精度までは確定しません。

この結果は**構造と照合件数の診断**です。全データの正確さ、完全なJSONスキーマの検証、匿名化した実応答fixtureの代わりにはなりません。
画面の共有時は、診断欄以外に表示された個人情報を含めないでください。
