# Sirius 学習支援Chrome拡張

東京農工大学のSirius LMSに、科目横断の課題・小テスト一覧を追加する非公式Chrome拡張です。
仕様と実装順序は [計画Issue #1](https://github.com/hoki621/sirius-chromeextention/issues/1) を参照してください。

現在は**検証中の試用版（0.2.0）**です。Chromeのツールバーから、締切別に整理した科目横断の課題一覧を開けます。日時と残り時間、タイトル検索、科目・種別フィルター、手元の完了チェックを利用できます。
2026-09-20、Codex内蔵ブラウザのSiriusで4サイト・課題7件を取得し、開いていた公式一覧5件のタイトルと締切日時が一致しました。2026-10-02に利用者から旧版の通常Chromeへの追加・起動成功の報告を受けました。0.2.0のツールバー起動と課題リンクは自動・架空データで確認済みですが、実Siriusでの受け入れ検証は未完了です。

小テストは空応答のみ確認済みで、項目がある場合は「未対応」と表示します。期限未設定値も未確定のため、解釈できない値は「期限不明」とします。アカウント識別が未検証なので、科目フィルターと完了チェックはページ内限定です。再読み込み・ページ移動で消えます。
これは全機能の完成や公開可能の判定ではありません。[受け入れ記録](docs/acceptance.md) と [実機調査](docs/sirius-contract.md) を確認してください。

## 開発

Node.js 22 LTS（22.18.0以上、開発・CIは `.nvmrc` の22.23.2）とnpmを使います。
TypeScriptのテストはNode.js標準の型除去と `node:test` で実行します。

```sh
npm ci
npm run check
npm test
npm run build
```

`npm test` はURLの対象判定、権限、APIエラー・中止・並列上限、日時、応答検証、設定保存、ビルド済みコードと配布物の内容を検証します。
パッケージの検査でビルドも実行します。実際のSiriusへは接続しません。
GitHub Actionsも同じ4コマンドを実行します。

`npm run preview` で架空データの画面を `http://127.0.0.1:4173/` に表示できます。Siriusへは通信しません。
`?case=partial`、`empty`、`malformed`、`auth`、`html`、`rate`、`link-failure` で異常系を切り替え、`/narrow` で幅360pxのレイアウトを確認できます。「ツールバー起動を模擬」で開き、`?open=1` で自動表示します。プレビューコードは拡張の配布物に入りません。
`?storage=mock&open=1` を2つのタブで開くと、架空のstorageで表示設定と削除のタブ間反映を確認できます。`storage=fail-read` / `fail-write` / `fail-delete` でI/O失敗、`confirm=cancel`で削除取消を模擬します。このモードの確認ダイアログは承認/取消の固定値で、実際のChrome storageやネイティブダイアログの検証ではありません。

## Chromeへの読み込み

コミット固定の試用ZIPを作る場合は [配布準備手順](docs/packaging.md) を参照してください。ZIP作成は公開の承認ではありません。

1. `npm run build` を実行します。
2. Chromeの `chrome://extensions` を開き、開発者モードを有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」で、このリポジトリの `dist` ディレクトリを選びます。
4. 「Sirius 学習支援」が表示され、エラーがないことを確認します。
5. Chrome右上の拡張メニューから「Sirius 学習支援」をピン留めします。青地に白いSのアイコンです。
6. ログイン済みのSiriusの `/portal` ページを再読み込みし、ツールバーのSアイコンを押します。最初に一覧を開いた時だけ読み取りGETを開始します。他サイト・ログイン前・未対応画面では案内を表示します。

ソースを変更したら再ビルドし、拡張の更新ボタンを押してから対象ページを再読み込みしてください。
`probe-dist` は開発用の診断拡張で、一覧版とは別です。診断が終わったら診断版は無効化できます。

## 使い方

- 更新ボタンで再取得します。同一ページ内は5分キャッシュを利用し、開いたまま古くなっても自動通信は行いません。更新中は前回の一覧を消し、新しく取得できた項目から表示します。
- 「取得範囲・科目別の結果」で失敗・未対応の範囲を確認してください。正常な0件と取得失敗は別表示です。
- 課題タイトルを押すと、対応する科目の公式課題一覧へ移動します。表示中の公式「課題」ナビゲーションを再利用し、他科目はSakaiの科目別ツールGETで解決します。取得できない・複数の候補がある場合は「科目トップを開く（課題一覧のリンク未取得）」と明示します。Siriusでの新APIの互換性は実機確認が必要です。個別課題の提出・受験開始URLは使いません。
- 今日・明日から7日以内・それ以降を先に表示します。期限超過は件数付きで折りたたみ、検索時は展開します。科目・種類・完了表示は「絞り込み」から変更できます。
- 「自分のリストで完了」は提出状態とは無関係です。チェックした項目は非表示になり、「完了した項目も表示」で再表示・取り消しできます。
- 種類と完了項目の表示設定だけを端末に保存します。検索文字列・科目フィルター・完了チェック・課題データは永続保存しません。
- 閉じるボタンまたはEscapeで公式画面へ戻れます。開けない場合はログイン状態とSiriusページの再読み込みを確認してください。未知の画面構造には挿入しません。
- 「使い方・制限」内の「拡張の保存データを削除」はこの拡張の保存領域だけを削除し、LMSを変更しません。開いている対応版の各タブにも削除を通知し、ページ内の完了印・検索・科目フィルターを初期化します。無効化・削除はChromeの拡張管理画面から行えます。無効化後はSiriusを再読み込みしてください。

## 動作範囲とデータ

- 対象は `https://lms.sirius.tuat.ac.jp/portal` とその配下のトップレベルページです。クエリ付きURLも含みます。
- Manifest V3の静的content scriptを使います。API権限は `storage` のみです。
- Cookie値・パスワード・認証コードを読み取ったり保存したりしません。
- LMSへの通信はサイト・課題・小テスト一覧と科目別ツール情報の同一オリジンGETだけです。提出、受験開始、バックグラウンド処理は行いません。起動用ポップアップは「一覧を開く」というメッセージと成否だけを扱い、認証情報や課題データを取得・保存しません。
- 実行時依存はありません。TypeScript、esbuild、Nodeの型定義は開発時だけ使用します。
