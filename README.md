# Sirius 学習支援

東京農工大学のSirius LMSで、科目を横断して課題と締切を確認できる非公式Chrome拡張です。Chromeのツールバーから一覧を開き、課題名をクリックして公式の個別課題画面へ移動できます。

**現在はβ版です。** Chromeウェブストアには未公開ですが、[GitHub Releases](https://github.com/hoki621/sirius-chromeextention/releases)からダウンロードして使えます。東京農工大学のSiriusアカウントでログインしているChromeが必要です。

## できること

- 科目横断の課題を、今日・今後7日・それ以降・期限超過・期限不明に整理。
- 日本時間の締切日時と残り時間を表示。
- 課題名の検索、科目による絞り込み。
- 課題名から公式の個別課題画面へ移動。直接リンクを取得できない場合は、理由を表示して課題一覧へ案内。
- 手元の完了チェックで、済んだ項目を一覧から隠す。

完了チェックはSiriusの提出状態と連動しません。締切・提出状況の最終確認と提出操作は公式画面で行ってください。

## インストール

[リリース一覧](https://github.com/hoki621/sirius-chromeextention/releases)の最新のβ版を開き、Assetsから `sirius-<バージョン>-trial.zip` をダウンロードしてください。GitHubアカウントは不要です。`Source code` は拡張の導入用ZIPではありません。

1. ZIPを空のフォルダーへ展開します。
2. Chromeで `chrome://extensions/` を開き、デベロッパーモードを有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、展開した `manifest.json` があるフォルダーを選びます。ZIPそのものは選びません。
4. Chrome右上の拡張メニューから「Sirius 学習支援」をピン留めします。青地に白いSのアイコンです。
5. 大学アカウントで [Sirius](https://lms.sirius.tuat.ac.jp/portal) にログインし、ページを再読み込みしてSアイコンを押します。

読み込み先のフォルダーは、利用中は削除・移動しないでください。

## 使い方

- Sアイコンで一覧を開き、閉じるボタンまたはEscapeで公式画面へ戻ります。
- 検索欄で課題名を検索し、「絞り込み」で科目や完了項目の表示を変更します。期限超過の課題は折りたたまれています。
- 課題名をクリックして公式の課題画面を開きます。提出はSirius上で行ってください。
- 「自分のリストで完了」にチェックすると、その項目を隠します。「完了した項目も表示」で再表示・取り消しできます。
- 最新の課題情報を確認したいときは「更新」を押します。一覧を開き直すと、取得から5分以内は前回の情報を表示します。
- 「取得範囲・科目別の結果」で取得失敗や未対応の科目を確認できます。失敗を「課題がない」とは扱いません。

一覧が開かない場合は、Siriusへのログイン状態を確認し、Siriusページを再読み込みしてからSアイコンを押してください。

## 更新・削除

β版は自動更新されません。新しいZIPを別フォルダーへ展開し、`chrome://extensions/` で旧版を無効化してから、新しいフォルダーを読み込んでください。最後にSiriusページを再読み込みします。旧版と新版を同時に有効にしないでください。

拡張を削除する場合も `chrome://extensions/` から操作し、Siriusページを再読み込みしてください。

## β版の制限

- **小テストは未対応です。** 項目がある応答は未対応と表示します。
- 解釈できない期限は「期限不明」と表示します。APIから取得できた範囲だけを扱い、履修科目や課題の網羅性は保証しません。
- 検索・科目フィルター・完了チェックはページ内だけで保持し、再読み込みや移動で消えます。種類と完了項目を表示する設定だけを端末へ保存します。

## データの扱い

Siriusへのログイン状態をそのまま使うため、拡張にパスワードを入力する必要はありません。Cookieの値、パスワード、認証コードを読み取ったり保存したりしません。課題情報はページ内で扱い、開発者や外部サーバーへ送信しません。

提出・受験開始・採点やアクセス解析は行いません。

拡張にはSiriusページを読み取り・変更し、ログイン状態を使って通信する能力があります。「読み取り専用」は現行コードの方針であり、Chromeが書き込みを禁止する保証ではありません。導入・更新には本リポジトリのソースまたはGitHub Releasesを使用してください。

保存設定は「取得範囲・科目別の結果」内の「拡張の保存データを削除」で削除できます。詳しくは [データの扱い](docs/privacy.md) を参照してください。

## 不具合報告

[GitHub Issues](https://github.com/hoki621/sirius-chromeextention/issues) へ次の情報を報告してください。

- 拡張のバージョン、Chromeのバージョン、OS。
- 再現する操作と、期待した結果・実際の結果。
- 個人情報を除いたエラー文。

Cookie、認証情報、生のAPI応答、氏名・課題名・本文入りの画像は送らないでください。

## 開発する方へ

Node.js 22（22.18.0以上、23未満）とnpmが必要です。使用バージョンは [.nvmrc](.nvmrc) を参照してください。

```sh
git clone https://github.com/hoki621/sirius-chromeextention.git
cd sirius-chromeextention
npm ci
npm run check
npm test
npm run build
```

Chromeには生成した `dist` フォルダーを読み込みます。変更後は再ビルドし、拡張とSiriusページを再読み込みしてください。`npm run preview` で架空データの画面を確認できます。テストは実際のSiriusへ接続しません。
