# Sirius 学習支援

東京農工大学のSirius LMSで、科目を横断して課題と締切を確認できる非公式Chrome拡張です。Chromeのツールバーから一覧を開き、課題名をクリックして公式の個別課題画面へ移動できます。

現在のバージョンは **0.2.4（β版）**。利用者の大学アカウント・通常Chromeで導入と動作を確認し、0.2.3では個別課題への移動成功も報告されています。検証の詳細と未確認事項は [受け入れ記録](docs/acceptance.md) にまとめています。Chromeウェブストアには未公開です。

## できること

- 科目横断の課題を、今日・今後7日・それ以降・期限超過・期限不明に整理。
- 日本時間の締切日時と残り時間を表示。
- 課題名の検索、科目・種類による絞り込み。
- 課題名から公式の個別課題画面へ移動。直接リンクを取得できない場合は、理由を表示して課題一覧へ案内。
- 手元の完了チェックで、済んだ項目を一覧から隠す。

完了チェックはSiriusの提出状態と連動しません。締切・提出状況の最終確認と提出操作は公式画面で行ってください。

## インストール

### 試用ZIPから使う

[βリリース v0.2.4](https://github.com/hoki621/sirius-chromeextention/releases/tag/v0.2.4) のAssetsから `sirius-0.2.4-trial.zip` をダウンロードします。非公開リポジトリのため、閲覧にはリポジトリへのアクセス権が必要です。アクセスできない場合は配布者からZIPを受け取ってください。

1. ZIPを空のフォルダーへ展開します。
2. Chromeで `chrome://extensions/` を開き、デベロッパーモードを有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、展開した `manifest.json` があるフォルダーを選びます。ZIPそのものは選びません。
4. Chrome右上の拡張メニューから「Sirius 学習支援」をピン留めします。青地に白いSのアイコンです。
5. 大学アカウントで [Sirius](https://lms.sirius.tuat.ac.jp/portal) にログインし、ページを再読み込みしてSアイコンを押します。

更新版は別フォルダーへ展開し、旧版を無効化して新しいフォルダーを読み込んでください。その後、Siriusページも再読み込みします。

### ソースから使う

Node.js 22（22.18.0以上、23未満）とnpmが必要です。開発・CIで使うバージョンは [.nvmrc](.nvmrc) に固定しています。

```sh
git clone https://github.com/hoki621/sirius-chromeextention.git
cd sirius-chromeextention
npm ci
npm run build
```

Chromeへの導入手順で、このリポジトリの `dist` フォルダーを選びます。ソースを変更したら再ビルドし、拡張管理画面の再読み込みボタンを押してからSiriusページを再読み込みしてください。`probe-dist` は開発用の診断拡張です。

## 使い方

- Sアイコンで一覧を開き、閉じるボタンまたはEscapeで公式画面へ戻ります。
- 検索欄で課題名を検索し、「絞り込み」で科目・種類・完了項目の表示を変更します。期限超過は折りたたまれ、検索時には展開されます。
- 課題名をクリックして公式画面を開きます。提出画面や誓約の案内画面が開く場合もありますが、拡張が提出や誓約への同意を実行することはありません。
- 「自分のリストで完了」にチェックすると、その項目を隠します。「完了した項目も表示」で再表示・取り消しできます。
- 「更新」で再取得します。同一ページ内では5分間のキャッシュを使い、自動通信は行いません。更新中は新しく取得できた項目から表示します。
- 「取得範囲・科目別の結果」で取得失敗や未対応の科目を確認できます。失敗を「課題がない」とは扱いません。

開けない場合は、Siriusへのログイン状態とページの再読み込みを確認してください。対象はSiriusの `/portal` とその配下のトップレベルページです。

## β版の制限

- **小テストは未対応です。** 項目がある応答は未対応と表示します。
- 解釈できない期限は「期限不明」と表示します。APIから取得できた範囲だけを扱い、履修科目や課題の網羅性は保証しません。
- 検索・科目フィルター・完了チェックはページ内だけで保持し、再読み込みや移動で消えます。種類と完了項目を表示する設定だけを端末へ保存します。
- 通常Chromeでの導入・動作は利用者が確認しています。全課題状態、200%ズーム、提出フォームとの共存などの受け入れ確認は [検証記録](docs/acceptance.md) を参照してください。

## データの扱い

既存のログインセッションを使い、同じSiriusへの読み取りGETで一覧と個別課題リンクを取得します。通信はタブ単位で最大4並列です。Cookieの値、パスワード、認証コードを読み取ったり保存したりしません。課題情報はページ内で扱い、開発者や外部サーバーへ送信しません。

拡張のAPI権限は `storage` のみです。提出・受験開始・採点、自動取得、アクセス解析は実装していません。認証エラーや解釈できないHTML応答を受けた場合は、閉じたパネルの表示内容も含め学習情報を消去します。

保存設定は「取得範囲・科目別の結果」内の「拡張の保存データを削除」で削除できます。無効化・削除は `chrome://extensions/` から行い、Siriusページを再読み込みしてください。詳しくは [データの扱い](docs/privacy.md) を参照してください。

## βテスト・不具合報告

課題の表示と締切、個別リンク、検索・絞り込み、完了チェック、公式画面との共存を確認してもらえると助かります。

[GitHub Issues](https://github.com/hoki621/sirius-chromeextention/issues) へ次の情報を報告してください。リポジトリへアクセスできない場合は配布者へ伝えてください。

- 拡張のバージョン、Chromeのバージョン、OS。
- 再現する操作と、期待した結果・実際の結果。
- 個人情報を除いたエラー文。

Cookie、認証情報、生のAPI応答、氏名・課題名・本文入りの画像は送らないでください。

## 開発・検証

```sh
npm run check
npm test
npm run build
```

Node.js標準の `node:test` で、URL・応答の検証、エラーと中止、並列上限、日時、設定保存、ビルド済みコードと配布物を確認します。テストは実際のSiriusへ接続しません。GitHub Actionsでは依存のインストールと同じ検査を実行します。実行時依存ライブラリはありません。

```sh
npm run preview
```

`http://127.0.0.1:4173/` に架空データの画面を表示します。`?open=1` で自動表示、`?case=partial`、`empty`、`malformed`、`auth`、`html`、`rate`、`link-failure` で異常系、`/narrow` で360px幅を確認できます。`?storage=mock&open=1` を2タブで開くと設定同期・削除を模擬できます。`storage=fail-read` / `fail-write` / `fail-delete` と `confirm=cancel` で保存失敗・削除取消を模擬します。プレビューは実際のChrome権限・保存領域の検証を代替しません。

試用ZIPは、変更をコミットして作業ツリーをクリーンにした後、`npm run package:trial` で生成します。`releases/` にZIPとコミット・SHA-256を記録した `build.json` を出力します。生成物はGit管理しません。詳しくは [配布準備](docs/packaging.md) を参照してください。

仕様と実装計画は [Issue #1](https://github.com/hoki621/sirius-chromeextention/issues/1)、APIの実機調査は [Sirius契約調査](docs/sirius-contract.md) を参照してください。ライセンスとストア掲載情報は公開準備時に確定します。
