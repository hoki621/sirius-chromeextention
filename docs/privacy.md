# 試用版のデータの扱い

対象: Sirius 学習支援 0.2.4、2026-10-02の試用実装。公開前に所有者が最終確認する文書です。

本拡張は東京農工大学の公式提供ではありません。課題の正式な期限・提出状態はSiriusで確認してください。

## 通信

開いたSiriusページから、同じSiriusのサイト・課題・小テスト一覧へGETを送ります。取得した課題ごとに `deepLink` GETを1回行い、個別課題の公式URLを確認します。最大同時4件、同一ページ内の5分キャッシュを利用します。実際の課題画面へは利用者がリンクをクリックした時だけ移動します。ブラウザが既存のログインセッションを使用します。Cookieの値、パスワード、認証コードは読み取らず、保存しません。
外部サーバー、アクセス解析、広告、開発者への学習情報送信は実装していません。提出、受験開始、採点の操作もしません。
ツールバーのポップアップは、現在のタブへ固定の「一覧を開く」メッセージを送り、成否だけを受け取ります。課題データや認証情報をポップアップへ渡しません。サービスワーカーと自動取得はありません。

## 保存

| 情報 | 場所と期間 |
| --- | --- |
| 科目名、課題名、期限、取得結果、個別課題・課題一覧URL | ページ内メモリ。再読み込み・移動・ページ破棄で消去。再利用期限5分 |
| 検索文字列、科目フィルター、手元の完了印 | ページ内だけ。再読み込み・移動で消去 |
| 種類フィルター、完了項目を表示する設定 | `chrome.storage.local`。削除するまで端末に保持。同期ストレージは不使用 |
| 画面のホームリンクの識別部分 | アカウント変更検知のためページ内だけで比較。永続保存しない |

安定したアカウント識別が未検証なので、完了印や科目別設定を永続保存しません。Shadow DOMは表示の干渉を減らす仕組みであり、ページから情報を秘匿する境界ではありません。
401、または解釈できないHTML応答を受け取った場合は学習情報を消去します。通信していない間のセッション失効を即座に検知するものではありません。

## 削除・無効化

パネルの「取得範囲・科目別の結果」内の「拡張の保存データを削除」から、この拡張が保存したデータを削除できます。Siriusの課題や提出物は変更されません。
削除時は、表示設定を一度既定値へ更新してから保存領域を削除し、開いている対応版の各タブへ削除を通知します。これにより、未保存のページ内完了印・検索・科目フィルターも初期化します。この通知のために個人情報や新しい識別子を保存することはありません。削除に失敗した場合は、その旨を表示します。
Chromeの拡張管理画面から無効化またはアンインストールできます。無効化した後はSiriusのページを再読み込みしてください。

## 不具合報告

[GitHub Issues](https://github.com/hoki621/sirius-chromeextention/issues) にバージョン、操作手順、個人情報を除いた表示内容を報告してください。
Cookie、パスワード、認証ヘッダー、生のAPI応答、氏名・課題名・本文入りの画像は投稿しないでください。
